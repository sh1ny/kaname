# kaname_grid_spike

A disposable web spike: a 25-column grid over 200,000 seeded rows, used to
measure Flutter web scrolling, filtering, grouping and sorting on skwasm and
CanvasKit. It is not product code; see the `web-grid-spike` OpenSpec change
and the report, [`docs/spikes/web-grid.md`](../../docs/spikes/web-grid.md).
